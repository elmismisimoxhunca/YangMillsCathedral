We now have an $h^{1}$-dimensional family $\Phi$ to realize all the infinitesimal deforma-

tions at $\omega$. We want to show that $\Phi$ is (a) locally complete, i.e. any self-dual connection

sufficiently close to $\omega$ is gauge equivalent to one in $\Phi$; (b) locally universal, i.e. any

$C^{\infty}$ family of nearby self-dual connections is gauge equivalent to a $C^{\infty}$ family in $\Phi$;

(c) locally effective, i.e. no two self-dual connections in $\Phi$ sufficiently close to $\omega$ are

gauge equivalent by a small gauge transformation. For this we use the exponential

map $\exp A^{0}( \mathrm{~g}) \rightarrow \mathscr{G}$ and show the following

Lemma. There exists a neighbourhood $U$ of 0 in $A^{1}( \mathrm{~g})$ and $W$ of 0 in $A^{0}( \mathrm{~g})$ such

that for any $\tau \in U$, there is a unique $X \in W$ with $\mathrm{d}^{*}( \omega - \exp ( X ) ( \omega + \tau ) ) = 0$.

Proof.

\[ \begin{aligned}\exp ( - X ) ( \omega + \tau ) - \omega & = \mathrm{e}^{- X}\left(\nabla \mathrm{e}^{X}\right) + \operatorname{Ad}( \exp ( - X ) ) \tau \\ & = \nabla X + \tau + R ( X , \tau ) \end{aligned}\]

where $R ( t X , t \tau ) = t^{2}R ( X , \tau , t )$ and $R ( X , \tau , t )$ is $C^{\infty}$ in $t$ for small $t$ and in $\tau$ and the

1-jet of $X$.

Now

\[ \begin{aligned}\mathrm{d}^{*}( \exp ( - X ) ( \omega + \tau ) - \omega ) & = 0 \text{iff}\\ \mathrm{d}^{*}\mathrm{~d}X + \mathrm{d}^{*}\tau + \mathrm{d}^{*}R ( X , \tau ) & = 0 \end{aligned}\]

(6.3)

Applying $G$, we have

\[ X + G \mathrm{~d}^{*}\tau + G \mathrm{~d}^{*}R ( X , \tau ) = 0 , \]

since $H^{0}( \mathrm{~g}) = 0$. Take neighbourhoods $U_{1}\subset A^{1}( \mathrm{~g}) , W_{1}\subset A^{0}( \mathrm{~g})$ of the origin and

let $F$ be the mapping

\[ F : U_{1}\times W_{1}\rightarrow A^{0}( \mathrm{~g}) , \quad ( \tau , X ) \mapsto X + G \mathrm{~d}^{*}\tau + G \mathrm{~d}^{*}R ( X , \tau ) . \]

$R$ is continuous in the $\|_{k}$ topology on $A^{1}( \mathrm{~g}) \times A^{0}( \mathrm{~g})$ to the $\|_{k - 1}$ topology on $A^{0}( \mathrm{~g})$,

so by the Sobolev inequalities $F$ is continuous in the $\|_{k}$ topology for small enough

$U_{1}, W_{1}$. Hence $F$ can be extended to the completion and by (6.3) and the implicit

function theorem in Banach spaces, for sufficiently small $U$, any $\tau \in U$ admits a

unique solution $X ( \tau )$ in the completion of $A^{0}( \mathrm{~g})$, which is small. By elliptic regularity,

since $X$ satisfies the equation

[?line conf=0.42: \[ \Delta X + \mathrm{d}* R ( X , \tau ) + \mathrm{d}^{*}\tau = 0 , \]]

$X$ is $C^{\infty}$ if $\tau$ is $C^{\infty}$. Hence if $\omega'$ is self-dual and sufficiently close to $\omega$, there exists a

gauge transformation $\exp ( X )$ for small $X$ such that $\exp ( X ) \omega'\in \Phi$, and we have

local completeness.
