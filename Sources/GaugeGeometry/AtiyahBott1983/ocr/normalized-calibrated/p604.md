13. Equivariant cohomology

In this section we shall review some of the general facts about equivariant cohomology and

establish some of the more particular results that we have had to use.

We recall first that for any topological group $G$ the classifying space $B G$ is defined as the base

of a principal $G$-bundle whose total space is contractible. It is unique up to homotopy so that in

particular $H^{*}( B G )$ depends only on $G$. More generally if $G$ acts on a space $X$ we define $X_{G}$ as

the associated bundle over $B G$ with fibre $X$ and define the equivariant cohomology by

[?line conf=0.94: \[ H_{G}( X ) = H \left(X_{G}\right) , \]]

so that $H ( B G )$ is now the equivariant cohomology of a point. If $G$ acts freely on $X$ so that $X \rightarrow X / G$

is a principal $G$-bundle then the map $X_{G}\rightarrow X / G$ has contractible fibres and so is a homotopy

equivalence. Thus in this case

\[ H_{G}( X ) \cong H ( X / G ) . \]

Suppose now that $K$ is a closed normal subgroup of $G$, and that $X$ is a $G$-space on which $K$ acts

freely (with $X \rightarrow X / K$ a principal $K$-bundle). Then the quotient group $S = G / K$ acts on $Y = X / K$,

and we have

(13.1)

[?line conf=0.58: \[ H_{G}( X ) \cong H_{S}( Y ) . \]]

To see this let $E_{1}, E_{2}$ be the total spaces of universal bundles of $G , S$ respectively. Note that $G$ acts

on $E_{2}$ via $S$ so that $E_{1}\times E_{2}$ is also a free contractible $G$-space; we can thus take

\[ X_{G}= X \times_{G}\left(E_{1}\times E_{2}\right) . \]

[?line conf=0.78: Projecting onto $X \times{}_{G}E_{2}$ with fibre $E_{1}$ is a homotopy equivalence and]

[?line conf=0.80: \[ X \times_{G}E_{2}= Y \times_{S}E_{2}= Y_{S}\]]

so that $X_{G}\sim Y_{S}$ proving (13.1).
