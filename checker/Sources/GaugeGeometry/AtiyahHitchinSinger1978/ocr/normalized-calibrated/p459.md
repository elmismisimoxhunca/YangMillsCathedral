constant curvature metric is a solution of the self-dual equations, so we can determine

$a$. For the Riemannian connection $\Omega : \Lambda_{+}^{2}\rightarrow \Lambda_{+}^{2}$ is a scalar and is covariant constant,

hence both terms in (9.2) vanish and

\[ \lambda^{3}3^{\frac{3}{2}}+ a \lambda^{3}= 0 , \]

and so $a = - 3^{\frac{3}{2}}$.
