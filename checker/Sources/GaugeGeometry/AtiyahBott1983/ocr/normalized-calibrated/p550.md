4. The Yang-Mills equations

We turn next to the equations of variation of $L ( A ) = \| F ( A ) \|^{2}$, and because $\mathscr{A}( P )$ is naturally

an affine space, it suffices to vary $A$ along lines

\[ A_{t}= A + t \eta , \quad \eta \in \Omega^{1}( M ; \operatorname{ad}( P ) ) . \]

The first problem is therefore to compute $F \left(A_{t}\right)$ for such a variation.

To do this recall that a connection $A$ on $P$ induces a natural covariant derivative $\nabla_{A}^{X}$ on all

associated vector bundles of $P$. Thus if

\[ V ( P ) = P \times_{G}V \]

is associated with a representation

\[ \rho : G \rightarrow \operatorname{Aut}V , \]

then $A$ induces a way of differentiating sections $s$, of $V ( P )$ :

(4.1)

\[ s \rightarrow \nabla_{X}^{A}s , \]

in any given direction $X$ on $M$. This 'covariant derivative' then dually corresponds to a differential

operator

\[ \mathrm{d}_{A}: \Omega^{0}( M ; V ( P ) ) \rightarrow \Omega^{1}( M ; V ( P ) ) , \]

which finally extends uniquely to a differential operator

\[ \mathrm{d}_{A}: \Omega^{*}( M ; V ( P ) ) \rightarrow \Omega^{* + 1}( M ; V ( P ) ) , \]

compatible with the natural pairing

\[ \Omega^{*}( M ; R ) \otimes \Omega^{*}( M ; V ( P ) ) \rightarrow \Omega^{*}( M ; V ( P ) ) \]

given by multiplication. Compatibility simply means

\[ \mathrm{d}_{A}( \theta \wedge \omega ) = \mathrm{d}\theta \wedge \omega \pm \theta \wedge \mathrm{d}_{A}\omega . \]

Recall here that (4.1) is defined by the following construction. We have

\[ \Gamma ( V ( P ) ) = \operatorname{Map}_{G}( P ; V ) . \]
