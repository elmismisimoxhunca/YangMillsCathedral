These can be written directly in terms of $x$, without resort to the eigenvalues, and are clearly

smooth invariant functions. Why they are convex will be explained in § 12 when we discuss this

notion more systematically. Given such a $\phi$ we now define a function $\Phi$ on the space of $G$ -

connections over $M$ in the obvious way:

(8.3)

\[ \Phi ( A ) = \int_{M}\phi ( * F ( A ) ) . \]

This reduces to the Yang-Mills functional when $\phi ( x ) =$ trace $x^{*}x$ (corresponding to $k = 1$ in

(i) above). Since $\phi$ is invariant under the adjoint action, $\Phi$ is gauge-invariant. Taking $A_{t}= A + t \eta$

and computing as in §4 we see that

(8.4)

\[ \Phi \left(A_{t}\right) = \Phi ( A ) + t \int \left\langle \phi'( * F ( A ) ) , * \mathrm{~d}_{A}\eta \right\rangle \bmod t^{2}\]

where $\phi': \mathrm{g}\rightarrow \mathrm{g}$ is the derivative of $\phi$, i.e.

\[ \phi ( x + t y ) = \phi ( x ) + t \left\langle \phi'( x ) , y \right\rangle \bmod t^{2}. \]

From (8.4) we see that the gradient of $\Phi$, relative to the metric on the space of connections, is

(8.5)

\[ \operatorname{grad}\Phi = - * \mathrm{~d}_{A}\phi'( * F ( A ) ) . \]

This reduces to the formulae of §4 for the Yang-Mills functional when $\phi ( x ) = \operatorname{trace}x^{*}x$ so that

$\frac{1}{2}\phi'$ is the identity map $\mathrm{g}\rightarrow \mathrm{g}$. In general $\phi'$ is an equivariant map (relative to the adjoint action

of $G$ ) and so for any section $s$ of $\operatorname{ad}( P )$ the covariant derivative of $\phi'( s )$ can be obtained from that

of $s$ by the composition rule

(8.6)

\[ \mathrm{d}_{A}\phi'( s ) = \phi^{\prime \prime}( s ) \circ \mathrm{d}_{A}s . \]

[?line conf=0.92: This is most easily understood by viewing $s$ as an equivariant function $P \rightarrow \mathrm{~g}$ and noting that]

[?line conf=0.84: $\mathrm{d}_{A}s$ is just the horizontal part (relative to the connection $A$ ) of the ordinary differential $\mathrm{d}s$.]

From (8.5) and (8.6) we deduce at once

(8.7) a critical connection for the Yang-Mills functional $L$ is also critical for $\Phi$, and the converse holds if

$\phi$ is strictly convex.

By a strictly convex function we mean as usual a function for which the second derivative $\phi^{\prime \prime}$

is everywhere positive definite, so that the linear transformation $\phi^{\prime \prime}( s )$ in (8.6) is invertible. The

quadratic function trace $x^{*}x$ used for the Yang-Mills function is clearly strictly convex and any

(weakly) convex $\phi$ becomes strongly convex if we add a positive multiple of trace $x^{*}x$. We see

therefore that there are many functionals $\Phi$ that have precisely the same set of critical points as

the Yang-Mills functional $L$.

So far we have not really used the convexity of $\phi$, only the non-degeneracy of the second

derivative $\phi^{\prime \prime}$. Thus $- \phi$ would have had the same properties. The significance of convexity is

that the Hessian of $\Phi$ always has a finite Morse index. To see this we compute as in §4 and find that

the Hessian $H$ corresponds to the self-adjoint differential operator

(8.8)

[?line conf=0.94: \[ \Phi_{A}= \phi^{\prime \prime}( * F ( A ) ) \mathrm{d}_{A}^{*}\mathrm{~d}_{A}+ \text{lower order.}\]]

[?line conf=0.85: Since $\Phi$ is gauge invariant we can, as in §4, restrict ourselves to $\operatorname{ad}( P )$-valued 1-forms $\eta$ with]

[?line conf=0.64: $\mathrm{d}_{A}^{*}\eta = 0$, so that in (8.8) $\mathrm{d}_{A}^{*}\mathrm{~d}_{A}$ can be replaced by the covariant Laplacian]

\[ \Delta_{A}= \mathrm{d}_{A}^{*}\mathrm{~d}_{A}+ \mathrm{d}_{A}\mathrm{~d}_{A}^{*}. \]
