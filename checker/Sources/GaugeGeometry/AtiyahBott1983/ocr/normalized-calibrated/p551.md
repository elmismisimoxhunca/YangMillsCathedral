With all these functorial remarks out of the way, we have the following:

Lemma 4.5. Let $A_{t}$ be the line of connections

\[ A_{t}= A + t \eta , \quad \eta \in \Omega^{1}( M ; \operatorname{ad}( P ) ) . \]

Then the curvature of $A_{t}$ is given by

\[ F \left(A_{t}\right) = F ( A ) + t \mathrm{~d}_{A}\eta + \frac{1}{2}t^{2}[ \eta , \eta ] . \]

Proof. By definition, the horizontal lifts $\tilde{X}_{t}$ of a vector field $X$ on $M$ relative to $A_{t}$ are related by:

\[ \tilde{X}_{t}= X_{t}+ t \eta ( X ) \]

and, correspondingly, the vertical projections relative to $A_{t}$ are related by

\[ \omega_{t}= \omega - t \eta \circ \pi . \]

Expanding $\omega_{t}\left[\tilde{X}_{t}, \tilde{Y}_{t}\right]$ now yields

\[ \begin{aligned}F_{t}( X , Y ) & = \omega_{t}\left\{[ \tilde{X}, \tilde{Y}] + [ \tilde{X}, \eta ( Y ) ] + [ \eta ( X ) , \tilde{Y}] + t^{2}[ \eta ( X , \eta ( Y ) ] \}\right. \\ & = \omega_{0}[ \tilde{X}, \tilde{Y}] - t \eta [ X , Y ] + t [ \tilde{X}, \eta ( Y ) ] - t [ \tilde{Y}, \eta ( X ) ] + t^{2}[ \eta ( X ) , \eta ( Y ) ] , \end{aligned}\]
