Proposition 8.13. For any $A \in \mathscr{A}_{\mu}$, and for any convex invariant function $\phi$ on $\mathfrak{u}( n )$, we have

$\Phi ( A ) \geqslant \phi ( \mu )$.

We shall begin by proving (8.13) in the simple case when

\[ \mu_{1}= \mu_{2}= \ldots = \mu_{r}> \mu_{r + 1}= \ldots = \mu_{n}\]

so that the canonical filtration of the bundle $E$ has just two steps. This means that, for the holo-

morphic structure defined by $A \in \mathscr{A}_{\mu}$, we have an exact sequence of vector bundles

\[ 0 \rightarrow D_{1}\rightarrow E \rightarrow D_{2}\rightarrow 0 , \]

where $D_{j}$ has rank $m_{j}$, Chern class $k_{j}( j = 1,2 )$ so that $\mu_{1}= k_{1}/ m_{1}$ and $\mu_{n}= k_{2}/ m_{2}$. For con-

venience we shall use the notation $\mu^{j}= k_{j}/ m_{j}( j = 1,2 )$. The curvature $F ( A )$ can then be written

in the form

(8.14)

\[ F ( A ) = \left[\begin{array}{c c}F_{1}- \eta \wedge \eta^{*}& \mathrm{~d}\eta \\ - \mathrm{d}\eta^{*}& F_{2}- \eta^{*}\wedge \eta \end{array}\right] , \]

where $F_{j}$ is the curvature of the metric connection of $D_{j}, \eta \in \Omega^{0,1}\left(M , \operatorname{Hom}\left(D_{2}, D_{1}\right)\right) , \eta^{*}$ is its

transposed conjugate and $\mathrm{d}\eta$ is the covariant differential. Now let $f_{j}, \alpha_{j}$ be scalar $m_{j}\times m_{j}$ matrices

such that

(8.15)

[?line conf=0.95: \[ \begin{gathered}\operatorname{trace}f_{j}= \operatorname{trace}* F_{j}\\ \operatorname{trace}\alpha_{1}= \operatorname{trace}* \left(\eta \wedge \eta^{*}\right) = - \operatorname{trace}* \left(\eta^{*}\wedge \eta\right) = - \operatorname{trace}\alpha_{2}. \end{gathered}\]]

Then some elementary inequalities concerning convex invariant functions $\phi$ (which will be

treated in §12) show that

\[ \phi ( * F ( A ) ) \geqslant \phi \left[\begin{array}{c c}f_{1}- \alpha_{1}& 0 \\ 0 & f_{2}- \alpha_{2}\end{array}\right] . \]

The convexity of $\phi$, together with the fact that $M$ has normalized volume, then implies that

(8.16)

\[ \Phi ( A ) = \int_{M}\phi ( * F ( A ) ) \geqslant \phi \int_{M}\left[\begin{array}{c c}f_{1}- \alpha_{1}& 0 \\ 0 & f_{2}- \alpha_{2}\end{array}\right] . \]

But the Chern class $k_{j}$ of $D_{j}$ is given by

\[ k_{j}= \frac{\mathrm{i}}{2 \pi}\int_{M}\operatorname{trace}f_{j}. \]

Since $f_{j}$ is a scalar matrix this means that $\int_{M}f_{j}$ is a scalar matrix whose diagonal entries are

[?line conf=0.86: $- 2 \pi \mathrm{i}k_{j}/ m_{j}= - 2 \pi \mathrm{i}\mu^{j}$. Also from (8.15) (since $\eta \in \Omega^{0,1}$ ) it follows that -i trace $\alpha_{1}$ is non-negative]

and so

\[ \int_{M}\alpha_{1}= 2 \pi \mathrm{i}a_{1}, \]

where $a_{1}$ is a non-negative scalar $m_{1}\times m_{1}$ matrix. Then
